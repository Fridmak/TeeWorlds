# TeeWorlds

Многопользовательская 2D-игра-платформер на Python: клиент-сервер по TCP, несколько оружий,
хук, аптечки, карты и меню. Учебный проект, выросший из желания разобраться,
как устроен сетевой геймплей.

## Стек

- Python 3
- `pygame` — рендеринг, физика, ввод
- `PyQt5` — стартовое окно ввода имени/сервера
- `socket` + `threading` — TCP-клиент и сервер
- JSON — протокол сообщений и карты

## Возможности

- Локальный и сетевой режим: клиент подключается к серверу по TCP.
- Сервер принимает несколько клиентов и рассылает состояние игры.
- Карты в JSON, выбор уровня в меню.
- Физика: гравитация, коллизии, прыжки, ограничение скорости.
- Оружие: AWP, Desert Eagle, minigun, shotgun, RPG с взрывами.
- Хук (hook), аптечки, случайные зелья, двери.
- Здоровье, неуязвимость после спавна, урон и смерть.
- Читы для отладки: `HP`, `GOD`, `POWER`, `ANIME`, `JUMPER`, `TANK`, `RICO`, `SH1RO`.
- Меню: главное, ввод имени, выбор уровня.

## Архитектура

```
teewords.py              точка входа, PyQt-окно
backend/server.py        TCP-сервер, комнаты, рассылка состояния
backend/client.py        TCP-клиент, приём карты и данных
backend/game.py          игровой цикл, рендеринг, ввод
scripts/player.py        игрок, оружие, хук, здоровье
scripts/game_items/      оружие, пули, зелья, двери
scripts/blocks/          карта и блоки
main_menu/               меню и выбор уровня
maps/                    карты в JSON
```

## Как запустить

```bash
pip install -r requirements.txt
```

Сервер:

```bash
python backend/server.py
```

Клиент:

```bash
python teewords.py
```

В стартовом окне указать имя и адрес сервера (`localhost`, порт `3657`).
